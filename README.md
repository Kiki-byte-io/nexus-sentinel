# NEXUS//SENTINEL

**Cybersecurity intelligence and identity protection platform.** This is an 8th-semester Full Stack Development project.

| | |
|---|---|
| Core problem | **Problem 31: Hardened Authentication Service** |
| Extension (pending faculty approval) | **Problem 35: Web Server Log Analyser**, selected features only |
| Current milestone | **Lab 1**: responsive static webpage (HTML, CSS, vanilla JS, Tailwind CSS) with a Chart.js plugin |

> **Lab 1 is a demo build.** It contains no real authentication. All telemetry shown is **synthetic**, all IP addresses come from the RFC 5737 documentation ranges, nothing is stored in the browser, and no form data is ever sent over the network.

## Lab 1: two implementations

| Version | Folder | How it is produced |
|---|---|---|
| Manual | `lab-1/manual-version/` | Coded by the student. AI help is limited to explanation, guidance and code review, and is logged in `docs/lab-1/ai-prompts.md` |
| Antigravity | `lab-1/antigravity-version/` | Generated by Antigravity from `docs/lab-1/antigravity-prompt.md` |

Both versions are built from the same spec, [`docs/lab-1/screen-spec.md`](docs/lab-1/screen-spec.md), so they can be compared fairly.

### Screens
1. **Home** (`index.html`): cinematic landing page with an animated network visualisation
2. **Dashboard** (`dashboard.html`): threat-intelligence dashboard. **Chart.js is the plugin**
3. **Auth** (`auth.html`): sign-in and register UI with a password-strength meter. Demo only

### Tech stack
- Semantic HTML5, vanilla JavaScript (ES2020)
- Tailwind CSS v4 through `@tailwindcss/cli` (4.3.x). The compiled CSS is committed, so pages work without a build step
- Chart.js 4.x, **vendored locally** (`assets/vendor/chart.umd.js`). There is no CDN
- Fonts: Inter and JetBrains Mono (Google Fonts), falling back to the system font stack

### Running the manual version
```bash
cd lab-1/manual-version
npm install          # Tailwind CLI only (dev dependency)
npm run build        # compiles src/input.css → assets/css/styles.css
npx serve .          # or open with VS Code Live Server
```
Run `npm run build` again after changing any HTML class names or `src/input.css`.
